# Tri des carnets de santé

Petite page web pour trier les carnets de santé par classe.

1. On importe le fichier Excel de la liste des élèves (nom, prénom, classe).
2. On tape les premières lettres du nom d'un élève.
3. La classe s'affiche en grand.

La liste des élèves reste uniquement dans le navigateur de l'appareil utilisé.
Elle n'est envoyée nulle part et n'est pas stockée dans ce dépôt.

**Ne jamais ajouter le fichier Excel des élèves à ce dépôt.**

Lecture des fichiers Excel : [SheetJS](https://sheetjs.com/) (chargé depuis cdnjs).
